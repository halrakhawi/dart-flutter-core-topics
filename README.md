# Dart Flutter Core Topics

A structured course that covers the **core concepts of Dart programming language**, designed especially for students who want to start **Flutter development**.

This repository contains examples, explanations, and exercises that introduce Dart fundamentals step by step.

---

## Course Objective

The goal of this course is to help learners:

- Understand the **Dart programming language**
- Build a strong foundation before learning **Flutter**
- Practice **clean coding and problem solving**
- Prepare for **mobile app development using Flutter**

---

## Topics Covered

The course covers the following Dart core topics:

1. Introduction to Dart
2. Variables and Data Types
3. Operators
4. Control Flow
   - if / else
   - switch
5. Loops
   - for
   - while
   - do while
6. Functions
7. Lists
8. Sets
9. Maps
10. Null Safety
11. Object-Oriented Programming
12. Classes and Objects
13. Constructors
14. Inheritance
15. Polymorphism
16. Abstract Classes
17. Interfaces
18. Exception Handling
19. Asynchronous Programming
   - Future
   - async / await
20. Dart Collections
